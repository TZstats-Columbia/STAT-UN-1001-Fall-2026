## Question outline

1. Build a one-variable frequency table from 14 student transportation responses.
2. Convert one frequency-table count into a relative frequency.
3. Complete two empty cells in a two-way table for phone/computer ownership; Canvas grades the two whole-number entries.
4. Interpret a conditional proportion using the row total.
5. Interpret a conditional proportion using the column total.
6. Chapter 2.2 / Exercise 2.22-style advanced comparison of conditional proportions.
7. Exercise 3.1-style coin-toss reasoning after a streak.
8. Exercise 3.1-style disjoint-event reasoning with face cards and red cards.
9. Guided Practice 3.7-style disjoint events using one cafeteria lunch choice.
10. Identify when the disjoint addition rule cannot be used because events overlap.
11. Guided Practice 3.14-style Venn diagram: identify the overlap.
12. Exercise 3.7-style Venn diagram: compute "iPhone or Apple computer."
13. Exercise 3.7-style Venn diagram: compute "neither."
14. Exercise 3.7-style independence check from a Venn setup.
15. Check whether a proposed probability distribution is valid.
16. Guided Practice 3.20-style complement / at least / no more than reasoning using notification counts.
17. Independence with hypothetical New York and Boston rain probabilities.
18. Exercise 3.11-style multiplication under an independence assumption using a nongendered student-pair example.
