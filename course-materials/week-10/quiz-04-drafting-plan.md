# Quiz 4 Drafting Plan

## Recommendation

Use a **mixed paper format**, not an all-multiple-choice quiz and not a fully open-response quiz. In a 15-minute, 100-student course, selected-response items efficiently reveal common misconceptions, while two or three short written prompts assess the language and setup that make inference meaningful.

The revised Version A prototype uses:

- one multiple-choice item that requires students to reconcile sample size, confidence level, interval width, and compatible two-sided test decisions around the claim `p = 0.50`;
- one multi-part multiple-choice item that distinguishes the population claim, observed sample evidence, and p-value meaning;
- one structured news-story inference pipeline composed of multiple-choice decisions about a two-sided test; and
- one brief test decision, conclusion, and Type I error response.

This is a 20-point design: `4 + 4 + 7 + 5`. Most points require written reasoning, but each response is deliberately bounded so the quiz remains realistic in 15 minutes.

## Calculator and table policy

Do **not** require a calculator or normal table for Quiz 4.

- Supply standard errors, test statistics, p-values, and critical values when interpretation is the target.
- Use only mental-arithmetic-friendly operations when a short calculation reinforces the structure, such as `2 x 0.02` for a margin of error.
- Save longer computations and normal-tail lookups for guided practice and the final exam only when the task itself warrants them.

This choice keeps the assessment about statistical reasoning and problem solving rather than arithmetic speed, while keeping it compatible with a 15-minute time limit.

## News-story item

The job-lock survey is the first proposed context because it gives a well-defined population, a clear binary outcome, and a simple benchmark. It is self-contained: students need no memory of the article. The item asks them to identify `p`, select two-sided hypotheses, distinguish the null-model standard error from the confidence-interval standard error, set up the test statistic, and locate the two-sided p-value region.

For alternate forms, use a different story and statistical question rather than merely replacing percentages. Possible contexts include healthcare affordability, extreme-heat impacts, student transit use, or a campus service survey. Preserve the same scoring structure.
