# Mini-project 0: Question and Retrieval Trial

## Purpose

Turn an area of interest into a statistical question and test whether the course Data Search and Retrieval Assistant can locate appropriate data.

## In-Class Work

1. Choose one domain: weather, environmental sensors, disaster response, or 311 complaints.
2. Write a question that can be investigated with data. Make the population, place, time period, and variables as specific as possible.
3. Use the [Data Search and Retrieval Assistant](https://pingpong.hks.harvard.edu/group/735?assistant=3600) to locate a relevant dataset or subset.
4. Identify the cases, variables, variable types, values or units, target population or process, and available time and geographic coverage.
5. State one reason the retrieved data may not fully answer the question.
6. Revise the question so it better matches the available data.

## Submit

Submit one short document containing:

- Original statistical question.
- Revised statistical question.
- Data source or dataset name.
- Cases and variables, including variable types and units when relevant.
- Population, place, and time period.
- One important limitation.

Do not submit prompts, screenshots, or assistant conversation histories.

## Completion Criteria

Full completion credit requires a good-faith retrieval attempt, a question that could be investigated statistically, accurate identification of the main data elements, and a meaningful limitation. Assistant use itself is not graded.
