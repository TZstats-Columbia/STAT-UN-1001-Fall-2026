# STAT UN 1001 Course Development Workspace

This folder contains four canonical working documents for the Fall 2026 version of STAT UN 1001.

## Current Files

- `syllabus.md`: student-facing syllabus draft.
- `course-design-development.md`: course design rationale, development plan, and idea parking lot.
- `learning-objective-map.md`: week-by-week objective-to-activity and objective-to-assessment mapping.
- `instructional-team-guide.md`: instructional operations guide for the instructor and TAs.
- `development-log.md`: major decisions and workspace history.
- `AI-activities-design.md`: supplemental note on how AI-aware activities should support, rather than replace, introductory statistics goals.

## Source Anchors

- OpenIntro Statistics: primary textbook and teaching-resource source.
- Veridical Data Science: project and responsible data-analysis framework, especially the data science life cycle and PCS.
